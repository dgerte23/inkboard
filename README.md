# 墨板 · InkBoard

> This HTML was developed for the Chinese people, so it is not available in other languages.

一个纯前端、可离线使用的自由白板。无需安装依赖、无需联网，双击即可开始。
![墨板界面预览](preview.png)
打开方式
最简单：双击 `index.html`，或双击 `启动墨板.bat`。
推荐（本地服务器，缓存更稳定）：
```bash
  cd inkboard
  python -m http.server 8765
  ```
然后浏览器访问 http://127.0.0.1:8765/。
功能一览
绘画
钢笔自由绘制，拖动即可画线；鼠标右键拖动也能随时画线。
画笔颜色支持色板、原生取色器和十六进制输入。
粗细 1–40 px 无级调节；文字字号 12–120 px。
橡皮擦逐点擦除，手绘线条会被局部切断；画板底部的垃圾桶可一键清空。
撤销 / 重做，最多保留 80 步。
完善的缓存：自动保存当前画板，刷新或下次打开自动恢复。
颜色管理
18 格最近使用颜色，自动记住下次直接点选。
5 组自带预设：基础色、莫兰迪、糖果色、霓虹、大地。
自建颜色文件夹：新建、折叠、加入当前颜色、移除颜色、删除文件夹。
颜色夹和最近颜色保存在本机，下次打开继续用。
选择与编辑
选择工具：点选、Shift 多选、拖出选框框选。
拖动移动；单选时拖动四角控制点缩放。
选框工具条支持复制、置顶、置底、删除。
双击文字可直接重新编辑。
支持方向键微移、Shift 加速、`Ctrl + D` 复制、`Ctrl + A` 全选。
图形
2D：直线、箭头、矩形、圆形、三角形、菱形、五角星、五边形、六边形、对话气泡。
3D：立方体、长方体、圆柱体、球体、金字塔、圆锥、六棱柱（带明暗面）。
拖动绘制，按住 `Shift` 等比 / 45° 吸附；2D 图形可切换填充。
图形同样支持选中、移动、缩放、层级调整和擦除。
文字
点击画板输入，支持多行；`Ctrl + Enter` 或点击别处完成，`Esc` 取消。
选择工具下双击已有文字即可修改。
文字颜色、字号跟随当前画笔设置。
计时与时间
顶部显示现实日期与时间。
可切换 24 小时制 / AM·PM，可开关秒数显示。
秒表：开始、暂停、继续、重置。
倒计时：自定义时 / 分 / 秒，或使用 1–60 分钟快捷预设。
倒计时结束提示音 + 画面提醒；可开启可拖动的浮动计时器。
画板与主题
画板尺寸自定义（320–4000 px），内置 A4 横竖、16:9、4:3、方形预设。
画板底色自定义 + 7 种底色预设。
背景纹理：纯色、点阵、网格、横线。
画板缩放：按钮缩放、`Ctrl + 滚轮`、适应窗口、1:1。
界面主题色自定义（10 个预设 + 任意取色），深浅色界面切换。
界面主题不会改变画板内容颜色。
保存与导出
停止操作约 0.65 秒后自动缓存。
手动版本快照：命名、载入、删除，最多保留 40 个。
导出 PNG 图片（2 倍清晰度，包含画板底色与纹理，不包含选框）。
导出 / 导入 JSON 源文件，可在不同浏览器或设备间备份迁移。
快捷键
操作	快捷键
选择 / 钢笔 / 橡皮 / 文字	`V` / `P` / `E` / `T`
撤销 / 重做	`Ctrl + Z` / `Ctrl + Y` 或 `Ctrl + Shift + Z`
删除选中	`Delete` / `Backspace`
复制选中	`Ctrl + D`
全选	`Ctrl + A`
微移 / 加速微移	方向键 / `Shift + 方向键`
置底 / 置顶	`[` / `]`
立即保存	`Ctrl + S`
缩放画板	`Ctrl + 滚轮`
取消选择 / 关闭弹窗	`Esc`
查看完整快捷键	顶栏 `?`
数据说明
所有内容只保存在浏览器本地 `localStorage` 中，不会上传任何服务器。键名如下：
`inkboard.v1.doc`：当前画板、尺寸、背景与对象
`inkboard.v1.settings`：颜色、粗细、主题、时钟、音效等偏好
`inkboard.v1.palette`：最近颜色与自定义颜色夹
`inkboard.v1.saves`：手动保存的版本快照
清除浏览器站点数据会同时清除白板缓存，重要内容建议导出 JSON 或保存快照。
文件结构
```
inkboard/
├─ index.html          页面骨架
├─ css/style.css       界面样式与响应式布局
├─ js/util.js          颜色、时间、几何等通用工具
├─ js/shapes.js        2D / 3D 图形绘制与命中检测
├─ js/store.js         本地存储与真彩预设
├─ js/timer.js         秒表 / 倒计时引擎
├─ js/app.js           画板交互、选择、缓存、导入导出
├─ favicon.svg         站点图标
├─ preview.png         界面预览
├─ 启动墨板.bat        Windows 一键打开
└─ README.md
```
兼容性
推荐使用较新的 Chrome / Edge / Firefox / Safari。3D 图形与文字使用 Canvas 2D 绘制，不依赖 WebGL。界面针对桌面端设计，并提供了平板 / 手机下的折叠侧栏布局。
